# Crime Investigation SQL Project

## Project Overview
This project is a SQL-based Crime Investigation and Analytics System developed using PostgreSQL.

## Tools Used
- PostgreSQL
- pgAdmin 4
- SQL

## Database Tables
- Officers
- Suspects
- Locations
- Crime Scenes
- Evidence
- Witnesses

## Project Objectives
- Store crime investigation data
- Manage officers and suspects
- Track crime scenes and locations
- Record evidence and witness statements
- Analyze crime-related information using SQL queries

## SQL Concepts Used
- CREATE TABLE
- INSERT INTO
- SELECT
- WHERE
- JOIN
- GROUP BY
- ORDER BY
- Aggregate Functions
- Primary Keys
- Foreign Keys
